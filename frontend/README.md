# MGenetica Frontend

Vite + React app for the live MGenetica site.

## Run

```bash
npm ci
npm run dev
```

Local dev URL:

```text
http://127.0.0.1:5173/mgenetica/#consultoria
```

Production preview after `npm run build`:

```bash
npm run start -- --host 127.0.0.1 --port 4173
```

```text
http://127.0.0.1:4173/mgenetica/#consultoria
```

## Build And Test

```bash
npm test
npm run build
```

## Scope

- Home, consulting, training, auth, catalog, account, course pages and quizzes live here.
- Appwrite is backend of record for auth, functions, quizzes and learner progress.
- Static redirect files in `public/` preserve older URLs and send visitors into hash routes.
- Production deploy uses `dist/` generated by `npm run build`.

## Production Requirements

- GitHub Pages workflow must upload `frontend/dist`.
- Appwrite Web Platform must include `https://mgenetica.github.io/mgenetica/`.
- Admin runtime needs `ADMIN_EMAILS` and `APPWRITE_ADMIN_API_KEY`.
- Progress runtime needs `APPWRITE_ADMIN_API_KEY` or `APPWRITE_API_KEY`.
- Frontend env must expose Appwrite endpoint/project/function IDs when defaults change.

## Course Visual Assets

- Module visuals live under `frontend/public/course-assets/`.
- The source contract for rendering them is `frontend/src/data/courseVisualAssets.js`.
- Static SVGs render as lazy `<img>` elements with module-specific alt text.
- Interactive HTML calculators render in lazy iframes with `sandbox="allow-scripts"` and `referrerPolicy="no-referrer"`.
- Keep generated curriculum JSON separate from the visual-asset map so future curriculum imports do not overwrite asset metadata.
- When replacing or adding an asset, update both the public file and `courseVisualAssets.js`, then run `npm test` and `npm run build`.
