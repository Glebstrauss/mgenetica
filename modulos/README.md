# Módulos gerados

Esta pasta guarda saídas do fluxo didático do `course-engine`.

Arquivos revisados podem ser versionados:

- `*.revision.md`
- `*.gate.md`
- `*.docx`

Arquivos intermediários com trechos recuperados devem ser revisados antes de entrar no Git:

- `*.prompt.md`
- `*.audit.md`
- `*.sources.json`
- `log.json`

Nesta branch há uma saída piloto de M1 para provar que o gate funciona no MGenética.
