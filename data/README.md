# Pasta `data/`

Esta pasta armazena arquivos simulados usados nas práticas dos módulos.

- `modulo01_simulado.csv` até `modulo21_simulado.csv` podem ser gerados executando os scripts da pasta `scripts/`.
- `course-content.yml` guarda mapa-base do conteúdo de estudo.
- `course-content-expansion.yml` guarda explicações ampliadas.
- `course-practice.yml` guarda exemplos numéricos, laboratórios R e quizzes científicos dos módulos prioritários.
- `glossary.yml` guarda termos do glossário técnico.
- Mantenha aqui também metadados e descrições dos conjuntos de dados futuros.
