# MGenética House Style

Pacote inicial de aplicação do brand MGenética em materiais institucionais.

## Regra

Não editar originais em `identidade_visual/House Style`. Este diretório é novo e isolado.

## Estrutura

- `00-brand-source/`: logo original, tokens e referências.
- `01-logo/`: pacote de logo em PNG/SVG.
- `02-slides/`: modelos de apresentação.
- `03-documentos/`: modelos de documento técnico.
- `04-social/`: templates sociais.
- `05-templates-web/`: templates HTML editáveis.
- `06-manual/`: manual da marca.
- `99-checks/`: checklist visual.

## Brand base

- Navy: `#0A1F38`
- Blue: `#1A4B78`
- Cyan: `#00A8D6`
- Surface: `#F7F9FC`
- Tint: `#EEF3F9`
- Display: Lora
- Body: DM Sans
- Logo real: `01-logo/PNG/mgenetica-logo-principal.png`
