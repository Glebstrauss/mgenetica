# Logo MGenética

## Arquivos

- `PNG/mgenetica-logo-principal.png`: logo bitmap real.
- `SVG/mgenetica-logo-site.svg`: versão SVG existente para site.
- `SVG/mgenetica-logo-dark.svg`: versão SVG existente para fundo escuro.

## Uso

- Fundo claro: preferir logo principal se contraste estiver bom.
- Fundo escuro: usar versão escura/SVG quando legível.
- Avatar: usar logo quadrada com respiro.

## Limite atual

O arquivo principal é bitmap `1024 x 1024`. Para impressão grande, precisa vetorizar SVG fiel.

## Não fazer

- Não distorcer.
- Não recolorir manualmente.
- Não aplicar sombra pesada.
- Não usar sobre fundo visualmente poluído.
