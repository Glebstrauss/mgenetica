## Checklist rápido

- [ ] A marca parece científica.
- [ ] A marca parece confiável.
- [ ] A marca parece moderna.
- [ ] A primeira dobra parece agradável e premium.
- [ ] A marca conversa com melhoramento genético animal.
- [ ] A marca funciona para cursos online.
- [ ] A marca funciona para consultoria.
- [ ] A marca funciona para artigos e documentos técnicos.
- [ ] A marca funciona para certificados.
- [ ] A marca funciona para Instagram e slides.
- [ ] A paleta parece coerente com o site publicado.
- [ ] Os cards estão compactos e não parecem caixas grandes.
- [ ] A página parece menos inventário de componentes e mais apresentação de marca.
- [ ] O visual não parece clínica veterinária.
- [ ] O visual não parece laboratório genérico.
- [ ] O visual não parece infantil.
- [ ] O visual não está poluído.
