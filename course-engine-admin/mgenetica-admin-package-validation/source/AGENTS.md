# MGenética course content — instruções locais

Este curso usa o `course-engine` como motor de geração didática.

Regras:

1. Usar português BR.
2. Usar Biblioteca Científica DuckDB como fonte primária.
3. Nunca inventar referência.
4. Nunca sobrescrever `modulos/*.md`, `modulos/*.docx`, `*.sources.json` ou `*.audit.md` sem confirmação explícita.
5. Manter sequência de graduação: genética básica → genética de populações → genética quantitativa → parâmetros genéticos → seleção → parentesco/endogamia → avaliação genética → genômica.
6. Toda geração deve salvar manifesto de fontes.
7. Usar sempre cavalos/equinos como espécie exemplo nos textos, cálculos e scripts.
8. Texto final deve ter referências em norma científica padrão usando `referencias.yml`. Origem de trecho, página, score, hash e caminho ficam só em `*.sources.json`/`*.audit.md`.
9. Nunca usar `Livro1`, `[S. l.]`, `[s. n.]` ou `[s. d.]` na seção `Referências` final.
