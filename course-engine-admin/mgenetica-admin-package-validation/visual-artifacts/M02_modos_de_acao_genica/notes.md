# M2 — Modos de ação gênica

## Artefato: `modos-de-acao.svg`

**Conceito visualizado:** Comparação dos três modos de ação gênica — aditivo, dominância e sobredominância — em um gráfico de valor genotípico × genótipo.

**Por que este artefato:** M2 exige enxergar a diferença entre efeitos no espaço genotipo→fenótipo. O gráfico torna imediato ver quando a linha é reta (aditivo), curva (dominância) ou tem pico no heterozigoto (sobredominância).

**Sugestão de uso no site:** Embutir na seção 'Conceito técnico' de M2 com `<img>`.
